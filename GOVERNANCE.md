# GOVERNANCE.md

## Overview
FTAI Spec is governed by the FolkTech AI team. Changes to the specification are reviewed and merged quarterly.

## Decision Making
- All proposed changes must go through Pull Requests.
- Pull Requests require two approvals before merge.
- Emergency patches can be fast-tracked by CEO approval.

## Steering Committee
- CEO (Mike Folk)
- Senior Dev (Jarvis AI + O3 AI)
- Open Source Contributors (review-only tier)

## Release Cadence
- Major releases: every 6 months
- Minor updates: quarterly
- Emergency patches: as needed
